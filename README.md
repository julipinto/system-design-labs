# System Design Labs

Laboratórios visuais e interativos para estudar System Design.

Notas pessoais de estudo, escritas com minhas palavras. Fonte: artigos públicos de Matheus Fidelis em
[fidelissauro.dev](https://fidelissauro.dev). Sem vínculo com o autor ou com qualquer curso.

**Módulos**
- [Protocolos de Rede](labs/protocolos-de-rede/index.html): OSI numa figura interativa, IP, TCP/UDP, TLS, DNS, DHCP, HTTP e tempo de resposta.

**Rodar local:** `npx serve .` e abrir o endereço mostrado.

**Gerar a página de um módulo:** `node labs/protocolos-de-rede/build.mjs`.

O kit isométrico em `tools/anatomy/` é MIT (ver `tools/anatomy/LICENSE`).
