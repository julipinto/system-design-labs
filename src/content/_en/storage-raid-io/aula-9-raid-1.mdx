<p>In RAID 0, D2 died and took A2 and A6 with it, and pedidos.db along with them. The problem is that each block existed in only one place. If each block exists on two disks, losing one stops meaning losing the file.</p>

<OneLiner>RAID 1 writes everything to two identical disks, so if one dies the other keeps serving, at the cost of half the space.</OneLiner>

<HowItWorks>
<ol class="flow steps">
  <li>The store puts <strong>pedidos.db</strong> on 2 disks of 1 TB (D1 and D2).</li>
  <li>Each write goes to <strong>both disks</strong>: A1 on D1 and D2, then A2 on both. The second is an exact copy (a mirror), so write speed is that of a single disk.</li>
  <li>On reads, the controller splits the work: A1 comes from D1 and A2 comes from D2, at the same time. <strong>Reads</strong> reach ~2x.</li>
  <li>When D2 dies, D1 has the same blocks and takes over <strong>with no downtime</strong>. The store doesn't even notice. You swap the disk and the controller copies D1 onto the new one (<strong>rebuild</strong>).</li>
  <li>The price is space: the capacity is that of a single disk. 2 x 1 TB gives <strong>1 TB usable</strong> (50%).</li>
</ol>
</HowItWorks>

<WhyItMatters>
  <li>It is the basics for the operating system, the database and small critical things.</li>
  <li>Simple to understand and to recover: the disk that survived is already a complete disk.</li>
  <li>During the rebuild, D1 is the only copy. If it fails now, the file is lost.</li>
  <li><strong>RAID is not a backup.</strong> If someone deletes a table, the mirror deletes it too, instantly.</li>
</WhyItMatters>

<Deep min={3}>
  <h4 class="deep-h">The math</h4>
  <ul>
    <li><strong>Minimum:</strong> 2 disks.</li>
    <li><strong>Usable capacity:</strong> the size of 1 disk. 2 x 1 TB = 1 TB (50%).</li>
    <li><strong>Failures tolerated:</strong> 1 (with N copies, N - 1).</li>
    <li><strong>Write penalty:</strong> 2 (writes to both disks).</li>
    <li><strong>Read:</strong> up to 2x, reading from both. <strong>Write:</strong> same as one disk.</li>
  </ul>
  <h4 class="deep-h">See it on Linux (mdadm)</h4>
  <pre><code>{"sudo mdadm --create /dev/md0 --level=1 --raid-devices=2 /dev/sdb /dev/sdc\ncat /proc/mdstat\n# [UU] = both disks ok, [U_] = one disk dropped (degraded)"}</code></pre>
  <h4 class="deep-h">Cost</h4>
  <p>You pay for 2 disks to use 1. In exchange, recovery is fast: just copy the good disk to the new one.</p>
